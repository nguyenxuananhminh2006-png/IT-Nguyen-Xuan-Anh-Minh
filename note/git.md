# Git
## 1. Git là gì?
Git (Version Control - quản lý phiên bản) là hệ thống giúp theo dõi và quản lý các thay đổi của dự án.
## 2. Repository
Repository (repo - kho lưu trữ) là nơi Git quản lý một dự án.
## 3. Một số lệnh cơ bản
- `git init` → khởi tạo Repository.
- `git add` → chọn thay đổi để chuẩn bị ghi nhận.
- `git commit` → ghi nhận một phiên bản.
